Straight answer: **the standard is DB-backed.** Real e-commerce never hardcodes products — Postgres/MySQL + cache + search index, catalog edited by merchandisers without deploys. So yes, "standard" = database.

But standard is standard *because* real catalogs are huge, mutable, multi-team. That's the problem it solves — not one you have at 130 static items. Standard ≠ right-for-context.

**Now the key thing, since you want robust:** for static data, code is *more* robust than a DB, not less. Robustness ranking, serving a catalog:

1. **In-code / build-time** — no runtime dep, can't fail. Most robust possible.
2. **DB + static/ISR rendering** — robust: DB hit at build/revalidate only, serves last-good static if DB down.
3. **DB, query-per-request** — *least* robust. Every page load depends on DB uptime + pool + latency. Supabase free-tier nap = full outage.

So "robust + DB" does NOT mean Redis. It means the pattern real robust Next shops use (Next.js Commerce, Shopify-backed sites):

**DB = source of truth, serving = static / ISR. Decouple serving from DB availability.**

- Products table in Supabase → FKs for cart/order/reviews, editable.
- Product list + `/product/[id]` **statically generated + revalidate** (Next 16: `generateStaticParams` + time-based revalidate / the `use cache` directive — check exact API in `node_modules/next/dist/docs/`, this Next differs from norms).
- DB touched only on build/revalidate, never per user request.
- Supabase paused? ISR serves stale static catalog. Users still shop.
- Images stay in `public/` (or Blob).

That's both the standard *and* the robust answer. Redis adds a failure point for zero gain here — Next's own cache is your cache layer.

**Honest caveat:** most robust of all is still pure code. DB buys you dynamic price/stock/add-SKU without redeploy. Want that editability → DB + ISR. Don't → code already wins on robustness.

Given "robust" is the driver: **DB + ISR, no Redis.** Want me to plan that migration — products table + seed from current catalog + static/ISR wiring?
